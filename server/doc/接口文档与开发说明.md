# 接口文档与开发说明

面向 **admin** 后台脚手架：前后端分离（`web/` SoybeanAdmin + `server/` Spring Boot API），后端包名 `com.ylmao.admin`，Sa-Token 鉴权，MyBatis-Plus 访问 MySQL，Redis 承载会话与缓存。

| 资源 | 说明 |
| --- | --- |
| 数据库种子 | `doc/admin_soybean.sql` |
| 前端 | 仓库根目录 `web/`（Vue 3 + Naive UI）；[Soybean 文档](https://docs.soybeanjs.cn) |
| Nginx 示例 | `doc/nginx-admin.example.conf` |

本文只摘 **接口与联调** 必需约定；URL/PO/DTO 等完整规范见本文第 5 节、根目录 `AGENTS.md` 及仓库内 `user` / `role` / `post` 样板代码。

### 为新模块补充文档注解

对照 **`PostController`**（`@Tag` + 各 JSON 方法上的 `@Operation`）：

- 类上 `@Tag(name = "…", description = "…")`
- 列表/增删改/唯一校验/启停等 JSON 接口加 `@Operation(summary = "…")`

## 1. 鉴权

| 项 | 说明 |
| --- | --- |
| 登录 | `POST /api/admin/auth/login`（账号、密码、验证码）；成功返回 token，前端写入本地并在后续请求头携带 |
| 请求头 | **`saToken: <token>`**；CORS 白名单见 `SaTokenConfigure` |
| 权限 | `@SaCheckPermission("模块:资源:动作")`；权限码与菜单种子 `perm_code` 一致 |
| 未登录 | 业务码 `401` |
| 无权限 | 业务码 `403` |

调试 Swagger：先浏览器登录后台，再打开文档页；可在 **Authorize** 中填写请求头 `saToken`。

## 2. 统一返回与异常

JSON 响应体为 **`com.ylmao.admin.common.R`**：

| 字段 | 含义 |
| --- | --- |
| `code` | `200` 成功；业务失败常见 `500`；鉴权 `401` / `403` |
| `msg` | 提示文案 |
| `data` | 载荷；无数据可为 `null` |
| `count` | 仅分页列表：总条数（与 `data` 列表并列） |

成功：`R.ok()` / `R.ok(data)` / `R.page(list, total)`；Controller 可用 `BaseController` 的 `pageData(data, count)`。  
业务失败在 Service 抛 **`BusinessException`**，由全局异常处理写成 `R.fail(...)`。  
基础校验放在 DTO（`@Valid`）；Controller 不重复做字段级与业务规则校验。

---

## 3. 分页

列表接口使用 **`PageQuery`**：

- `page`：页码，默认 `1`
- `limit`：每页条数，默认 `10`，最大 `100`

典型链路：`PageQuery` + 模块 `XxxList` DTO → Service `selectPage` → `pageData(records, total)`。

## 4. 前端请求约定

- API 集中在 `web/src/service/api`，走项目既有 `request` / hooks 封装
- 提交 JSON：`Content-Type: application/json`
- 错误：展示后端业务 `msg`，不要静默吞错
- 分页：响应 `data` 为列表，`count` 为总数（见 `web/src/hooks/common/table.ts`）
- 调用后端 API 处可加一行简短注释（列表、唯一校验、保存、启停、删除等）

HTTP 动词：新增 **`POST`**，修改 **`PUT`**，启停 **`PATCH`**，删除 **`DELETE`**。

---

## 5. 模块开发规范（标准 CRUD）

1. **对照样板**：主参考 **`user`**，次参考 **`role`** / **`post`**（岗位含 OpenAPI 样板注解）。
2. **URL**：类上 `@RequestMapping("/模块")`，方法上只用动作（`/list`、`/add`、`/update`、`/delete`、`/updateEnabled`、`/checkName`…），**禁止**重复模块词（如 `/post/postList`）。
3. **Java 方法名**：可带模块前缀（如 `postList`）；与 URL 动作分离，见根目录 `AGENTS.md` 与 `user` / `role` 模块。
4. **分层**：Controller 只收 DTO、调 Service、返回 `R`；业务规则与唯一性等在 Service，失败抛 `BusinessException`。
5. **DTO / VO / PO**：增删改各用 `XxxInsert` / `XxxUpdate` record；列表返回 VO，不以 PO 作为请求体。
6. **菜单与权限码**：改菜单路由、`perm_code` 时同步 Controller、前端、`doc/admin_soybean.sql`（或迁移 SQL）。

验收：按本文 + 抄 `user` / `role` / `post` 完成列表 / 增 / 改 / 删 / 启停，并在 Swagger **admin** 分组中看到对应 JSON 接口。

## 7. 本地运行与常见问题

| 项 | 说明 |
| --- | --- |
| Profile | 默认 **dev**（`application.yml` 中 `spring.profiles.default`）；生产加 `--spring.profiles.active=prod` |
| 端口 | dev 默认 **8085**（见 `application-dev.yml`）；prod 默认 **8081** |
| MySQL / Redis | 连接信息在对应 profile 的 yml 中配置；导入 **`doc/admin_soybean.sql`** 初始化库表与种子 |
| 启动校验 | `SecurityConfigChecker` 要求 `sys_config` 中存在完整的 **`security.*`** 配置项；缺项会启动失败 |
| 包名 / 类名变更后登录报错 | Redis 中旧 Sa-Token 会话可能仍序列化旧类名；开发环境可 **`FLUSHDB`** 或删除 satoken 相关 key 后重新登录 |

更完整的安装、部署与 Nginx 示例见仓库根 **`README.md`**、`doc/nginx-admin.example.conf`。
