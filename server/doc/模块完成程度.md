# 模块完成程度

> 范围：Soybean 管理端页面是否接到真实后端。后端接口以 Controller 为准，前端以 `web/src/service/api` 与页面提交为准。
> 更新：2026-09-20

判定：

- **已完成**：列表与主要写操作走真实接口，数据进库。
- **未完成**：页面仍用本地假数据，或保存只弹成功、不请求后端。这些模块的后端接口大多已经存在。
- **部分完成**：主流程已接上，但菜单里承诺的个别能力页面还没接。
